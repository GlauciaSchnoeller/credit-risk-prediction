# Credit Risk Prediction

Repository created for Machine Learning experiments and tests using a credit risk prediction dataset.

## Objective

Explore, test, and compare different Machine Learning algorithms and evaluation metrics to predict credit card payment defaults.

## Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Models

- Logistic Regression
- Decision Tree
- Random Forest

## Status

In Progress.

**Note:** This repository is intended for educational purposes and experimentation.

## Dataset Reference

Yeh, I. (2009). Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository. 

DOI: [10.24432/C55S3H](https://doi.org/10.24432/C55S3H.)
